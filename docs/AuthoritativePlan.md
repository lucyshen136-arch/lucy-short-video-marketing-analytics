# Authoritative Plan

## Core Position
The project is a reproducible public GitHub research repository, not a webpage. Data analytics is the main line; marketing/business analysis is the application context; a dashboard is optional.

## Research Questions
1. Which topics, hooks, and narrative structures are associated with public engagement or Lucy's continued watching and memory?
2. Which value propositions, persuasion mechanisms, evidence types, and CTAs are associated with trust and action intention?
3. What interpretable differences appear across platforms, content types, and marketing-funnel stages?
4. Where do Lucy's human labels and AI suggestions agree, and which contexts are error-prone?
5. What content or marketing hypotheses should be tested next?

## Mandatory Deliverables
- Public GitHub repository with transparent iteration history.
- Reproducible 30-video Gold Dataset workflow.
- Data audit, at least three grouped/cross-tab analyses, association/uncertainty analysis, AI-label agreement analysis.
- At least three runnable SQL business queries, three core figures, and three to five evidence-based marketing insights.
- Stable logic in `src/`, deterministic tests, GitHub Actions, and clean-clone reproducibility.
- At least three documented AI failures/disagreements.
- Five-to-eight-minute professor-facing explanation.

## Boundary
Thirty selected videos form an exploratory, deeply annotated sample. They do not represent all young users and cannot establish causality between marketing methods and business outcomes. Use `exploratory study`, `observed pattern`, and `hypothesis`.

## Enhancements
- 100-300 lightweight extension dataset only if provenance, platform rules, public-data conditions, time, and quality permit.
- Dashboard only after the research release passes.
