# Start Here

This is the prepared-starter route.

1. Copy the extracted folder to a simple local path.
2. Open the directory containing `README.md` and `TASKS.md`.
3. Initialize Git only if the folder is not already a repository; create a baseline commit by staging reviewed starter paths explicitly.
4. Run `prompts/WORKSPACE_AUDIT.md` once. Do not run INIT.
5. After human review, execute S01 only.
6. Accept, checkpoint, and activate one next unit at a time.
